# probewasm

Probe structured JSON wasm payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/probewasm/

## Install / run

```bash
git clone https://github.com/theworker02/probewasm.git
cd probewasm
node src/cli.js
node --test
```
